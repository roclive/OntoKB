# OntoKB Windows 桌面程序

## 0.2.0 阅读工作台

桌面端与浏览器共用后端生成的 UI：文章摘要、关键要点、分段图谱漫游、平滑镜头、动态关系线、原始证据、实体查询和 Chat 无需维护两套页面。点击“新建摘要”粘贴文章正文，或通过菜单“阅读 → 新建文章摘要”（Ctrl+N）进入。生成后自动保存并刷新资料列表；视频通过 Chat 入库后同样自动刷新。

漫游支持暂停、前后段落和 6/10/15 秒速度。切换资料、打开助手或离开窗口会暂停。摘要按实体名称／别名匹配，只使用当前资料的已记录关系。没有匹配时不会虚构路径。系统开启减少动画时，镜头和脉冲动画自动降级。

启动时检查摘要／漫游功能标识，避免静默连接旧版后端。若提示旧版，请停止旧后端后重新启动应用。`src/ontokb/web/` 保存共享页面，后端按请求读取；修改 UI 后刷新桌面窗口即可生效。Python 后端功能改变仍需重启后端。

在 PowerShell 7 中运行 `./desktop/build.ps1 -Install`，会生成 Electron 程序，安装到 `%LOCALAPPDATA%\Programs\OntoKB`，创建桌面快捷方式并启动。构建需要 Node.js/npm 和现有 Python 环境。

首次启动自动启用 Windows 登录后后台启动。菜单/系统托盘中的“开机自动启动”可随时关闭或重新启用。关闭窗口只隐藏到托盘，定时任务可继续运行；从托盘选择“退出”结束桌面程序以及它自己启动的后端。已经运行的后端由原来的启动者管理。

这是本机集成版：Electron 已打包，Python、Codex 登录、代码和数据复用当前电脑。请保留项目目录与 Python 环境；另外任务修改的后端代码在后端重启后生效。无需复制知识库，也不会把登录凭证打进 Electron 包。搬到另一台电脑时需部署项目及 Python 依赖，再重新运行构建脚本。

输出在 `desktop/dist/OntoKB-win32-x64/OntoKB.exe`。运行时路径保存在构建生成的 `runtime.json`，不提交 Git。后端日志位于 `%APPDATA%\OntoKB\backend.log`。重建并覆盖安装前，请先从托盘退出 OntoKB。
