# OntoKB 0.3.0 Windows x64

此 ZIP 是 Electron 桌面客户端，**不是包含 Python 后端的一体化安装包**。解压到固定目录后运行 `OntoKB.exe`，不要直接在 ZIP 内启动。

1. 从同版本 GitHub 源代码部署 OntoKB，按仓库 README 安装 Python 依赖并配置所需服务。
2. 首次启动时选择项目根目录，以及已安装依赖的 `python.exe`（可使用虚拟环境的 `Scripts/python.exe`）。
3. 客户端启动本机 `127.0.0.1:8765` 后端；浏览器与桌面共用当前项目的数据和界面。已有后端需在代码更新后重启。

本版本加入 YouTube 多媒体摘要：可生成约 1–2 分钟的视频精剪和较长的原声漫游，并将截图、中文字幕、原声及文章摘要同步展示。图谱与原声段落可双向定位；原声进度条支持跨片段拖动，截图区域高度也可上下调整并记忆设置。

首次启动默认启用登录后自动后台启动，可在菜单或托盘关闭。关闭窗口仅隐藏；托盘“退出”可结束。移动解压目录后请重新切换自启动开关。

“视图 → 强制加载最新界面”（Ctrl+Shift+R）可刷新更新后的网页；确认前先保存草稿。Python 后端更新仍需重启后端。

客户端配置保存在 `%APPDATA%/OntoKB/runtime.json`，日志同目录。要切换项目，退出程序后删除该配置再启动。此发布包不包含开发者本机路径、凭证、数据库、文章、观看记录或个人知识库。源代码仓库的历史内容与此 ZIP 独立。

程序未签名，Windows 可能显示发布者未知。下载后可用配套 SHA256SUMS 文件核验完整性。
